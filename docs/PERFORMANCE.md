## Light index (dashboard, roadmap, account)
- `js/data/index-light.js` (`window.DATA_INDEX`, group `index`) is GENERATED by `node scripts/build-light-index.js`
  from questions/algos/lessons/sd/drills/companies: only the fields light screens read (id, topic, level, titles…).
- `App.lite(kind)` returns the full list once that group is loaded, else the light objects (`__light: true`).
  `App.stats()` / `App.dueItems()` go through it, so they work on light routes; views that need text still await
  their groups. i18n swaps only the fields light objects carry (English titles).
- `scripts/validate.js` fails (and prints the command) when the file is stale; `check-budget.js` caps `#/` at 1.2 MB
  including the shell, and roadmap/account data at 200 KB.
